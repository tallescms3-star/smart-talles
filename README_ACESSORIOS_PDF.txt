IMPORTANTE SOBRE PREÇOS:
O PDF apresenta nome, SKU e botão “Fotos e mais”, mas não apresenta os preços dos produtos.
Por isso, nenhum preço foi inventado: os 21 itens entram com preço R$ 0,00 e ficam bloqueados para inclusão no orçamento até que o preço seja preenchido em Administração.

Cada item também guarda o link individual do catálogo RDI quando esse link estava disponível no PDF.

Para preencher os preços:
1. Abra Administração.
2. Localize a seção Acessórios.
3. Digite o preço de cada item.
4. O preço passa a aparecer no catálogo e o produto poderá ser adicionado ao orçamento.

A sincronização inicial adiciona os novos acessórios ao banco existente sem apagar os produtos já cadastrados.
